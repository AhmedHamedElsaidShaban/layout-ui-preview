# Layout UI preview

Standalone browser preview of Ahmed Hamed's Layout Rive interface.

Serve this directory using a local HTTP server, or publish its root through GitHub Pages. The entry point is `index.html` and the animation asset is `main.riv`. The page loads Rive Canvas 2.36.0 from unpkg.

This demonstrates the interface only. After Effects operations and the extension's backend are not included. No extension source or credentials are required.

Suggested GitHub repository: `layout-ui-demo`. Enable Pages from the main branch, root folder. The repository owner and hosted URL must be confirmed after publication.
